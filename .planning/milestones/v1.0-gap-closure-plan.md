## 1) FMT-03 - Citation sufficiency audit

Goal:
Verify each technical claim in paper sections 01-07 has at least one semantically supporting IEEE reference.

Inputs:
- docs/paper/01-introduccion.md
- docs/paper/02-estado-arte.md
- docs/paper/03-alcance.md
- docs/paper/04-metodologia.md
- docs/paper/05-implementacion.md
- docs/paper/06-resultados-pruebas.md
- docs/paper/07-conclusiones.md
- docs/paper/08-referencias.md

Procedure:
1. Build a claim table with columns: claim text, file, line context, cited refs [N], support verdict.
2. For each claim with weak/missing support, either:
   - add a valid supporting IEEE citation already present in references, or
   - rewrite claim to match available evidence.
3. Ensure conclusions section does not introduce new citations.

Output evidence:
- docs/paper/data/fmt03-citation-audit.csv
- Optional patch updates to paper sections and references.

Done criteria:
- 100% technical claims marked Supported.
- No unresolved rows in audit CSV.

## 2) FMT-04 - Originality/paraphrase audit

Goal:
Confirm no copy-paste or mosaic plagiarism patterns in the paper draft.

Inputs:
- docs/paper/01-introduccion.md ... docs/paper/09-declaracion-ia.md

Procedure:
1. Run institutional plagiarism check tool (or approved equivalent).
2. Manually inspect flagged passages and rewrite for own wording while preserving meaning.
3. Keep citations attached to rewritten passages where applicable.

Output evidence:
- docs/paper/data/fmt04-originality-notes.md
  - tool used
  - flagged fragments summary
  - rewrite actions taken

Done criteria:
- No high-risk plagiarism flags unresolved.
- Notes document includes final reviewer sign-off.
